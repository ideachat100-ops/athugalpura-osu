## ✨ තාක්ෂණික එකතුව (Tech Stack)

* **Framework:** Next.js 16 (App Router + Turbopack)
* **Frontend:** React 19, TypeScript
* **Styling:** Tailwind CSS v4, Lucide Icons
* **3D Visuals:** Three.js / WebGL (Interactive Antique Brass Vajrayudha 3D Canvas)
* **Internationalization (i18n):** ද්විභාෂා පද්ධතිය (Sinhala `si` / English `en`)
* **SEO & Architecture:** Semantic HTML5, Schema.org Microdata, High-Speed Edge Pre-rendering

